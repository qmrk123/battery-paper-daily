📷 그래픽 초록 저장 (북마클릿)

아래 초록색 버튼을 브라우저 북마크바로 드래그하세요. 그런 다음 논문 페이지 (ACS·Wiley·RSC·Elsevier 등, 로그인된 본인 브라우저)에서 이 북마크를 클릭하면 그 페이지의 그래픽 초록을 DOI 이름으로 저장합니다.

📷 GA 저장  ← 이걸 북마크바로 드래그

이건 봇 차단 우회가 아닙니다. 선생님이 기관 구독으로 정당하게 접근해 직접 열어 본 화면에서, 본인 클릭으로 이미지를 저장하는 것뿐입니다. Cloudflare 등은 선생님이 사람으로서 이미 통과한 상태고요.

쓰는 법

  1. 위 📷 GA 저장을 북마크바로 드래그해서 설치.
  2. 논문 페이지를 본인 브라우저에서 엽니다 (그래픽 초록이 화면에 보이는 상태).
  3. 북마크 📷 GA 저장 클릭 → 이미지가 <DOI>.jpg 이름으로 다운로드됩니다(안 되면 새 탭에 열려요 → Ctrl+S로 저장). DOI는 클립보드에도 복사됩니다.
  4. 모아서 한 번에 사이트에 반영:
    python scripts/add_image.py --scan "C:/Users/user/Downloads"
  5. 또는 개별: python scripts/add_image.py <DOI 또는 논문ID> "저장한이미지.jpg"
  6. 끝나면 git add data/ site/img && git commit -m "img: manual GA" && git push → 카드에 표시.
